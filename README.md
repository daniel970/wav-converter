# WAV 일괄 변환기 (wav-converter)

폴더 안의 모든 음원 파일을 **WAV로 일괄 변환**하는 Windows용 GUI 도구.
입력 폴더의 하위 폴더 구조를 그대로 복제해서 출력 폴더에 저장합니다.

- **순수 Rust** — 외부 프로그램 설치 불필요. `wav-converter.exe` 하나만 복사하면 어디서든 실행.
- **거의 모든 포맷 디코딩** — mp3, flac, m4a/aac, alac, ogg, wav, aiff 등 (symphonia)
- **출력 규격 선택** — 원본 유지(무손실) / 16bit·44.1k / 16bit·48k / 24bit·48k / 24bit·96k
- **드래그&드롭** — 폴더를 창에 끌어다 놓으면 입력 폴더로 지정

## 사용법

1. `wav-converter.exe` 실행
2. **입력 폴더 선택** — 변환할 음원들이 들어있는 폴더 (하위 폴더까지 모두 탐색)
3. **출력 폴더 선택** — WAV가 저장될 폴더 (입력 폴더 구조를 그대로 복제)
4. **출력 규격** 드롭다운에서 원하는 형식 선택
5. **변환 시작** — 진행률과 파일별 결과가 표시됨

예) 입력 `C:\음악`, 출력 `D:\wav`, 파일 `C:\음악\앨범A\track1.mp3`
→ 결과 `D:\wav\앨범A\track1.wav`

## DAP용 파일명과 순서

- Windows에서는 변환과 순서 정리가 모두 끝나면 오른쪽 아래 완료 알림을 한 번 전송합니다. 성공·실패 개수와 이름/순서 경고 여부를 표시합니다. 알림 표시와 소리는 Windows 알림 설정 및 방해 금지 설정을 따릅니다.

- **파일명에서 아티스트 제거**를 켜면 `01 ミツキヨ - Unwelcome School.mp3`를 `01 Unwelcome School.wav`로 저장합니다. 번호가 없는 이름이나 패턴이 다른 이름은 유지합니다. 곡 제목 안의 ` - `는 유지합니다.
- 이 옵션은 파일명에만 적용하며 아티스트 태그 편집 기능은 아닙니다. 같은 이름의 출력이 있으면 새 WAV로 덮어씁니다. 임시 파일에 변환을 완성한 후 교체하므로 변환 실패 시 기존 출력은 유지합니다. 여러 입력이 같은 출력 이름이 되면 번호순으로 처리한 마지막 성공 결과가 남습니다.
- 변환 완료 후 성공한 결과의 파일명·하위 폴더명에 ASCII 이외의 문자(한글·일본어·중국어·악센트 문자 등)가 있으면 경고창을 한 번 띄웁니다. 숫자·공백·기본 영문 기호는 허용합니다. 검사 기준은 아티스트 제거가 적용된 최종 이름이며, 출력 위치보다 상위의 사용자 계정 경로와 음원 태그는 검사하지 않습니다.
- CD·곡 번호를 숫자로 비교해 순서대로 변환합니다 (`CD 2` → `CD 10`, `2` → `10`).
- **DAP 재생 순서 맞추기**는 기본으로 켜져 있습니다. 변환이 끝나면 출력 파일이 있는 폴더와 상위 출력 폴더의 항목을 번호순으로 다시 배치합니다. 기존 `Disc 2`가 먼저 만들어져 있어도 `Disc 1`부터 배치하며, 음원 내용을 다시 쓰지는 않습니다. 같은 폴더의 기존 파일도 함께 정리하며 Windows 숨김·시스템 항목은 제외합니다.
- 파일 잠금 등으로 정리에 실패하면 가능한 항목을 원위치로 복구하고 완료 화면에 오류를 표시합니다. 강제 종료로 `.wav-converter-order-...` 폴더가 남았다면 내부 파일을 확인하세요. 이 폴더를 삭제하지 말고 원래 위치로 복구한 뒤 다시 실행하세요.
- 순서 정리는 선택한 **출력 위치**에 적용됩니다. PC에서 변환한 뒤 탐색기로 SD카드에 복사하면 복사 과정에서 순서가 다시 바뀔 수 있으므로, DAP용으로는 SD카드를 출력 폴더로 선택하세요. 파일시스템이 요청한 순서를 제공하지 않으면 정리 실패로 표시합니다.

## 빌드 (Windows)

[Rust 설치](https://rustup.rs) 후:

```cmd
cargo build --release
```

결과물: `target\release\wav-converter.exe` (단일 실행 파일)

## 빌드 (macOS/Linux에서 Windows용 크로스 컴파일)

```sh
rustup target add x86_64-pc-windows-gnu
# (mingw-w64 툴체인 필요: macOS는 `brew install mingw-w64`)
cargo build --release --target x86_64-pc-windows-gnu
```

결과물: `target/x86_64-pc-windows-gnu/release/wav-converter.exe`

> macOS/Linux에서 그냥 `cargo run` 하면 같은 GUI가 그대로 떠서 동작 확인도 가능합니다.

## 지원 입력 포맷

mp3, flac, wav, m4a, aac, ogg/oga, aiff/aif/aifc, alac, caf, mp4(오디오), mka, mp1, mp2, wv, ape
등 symphonia가 지원하는 포맷. (지원하지 않거나 손상된 파일은 건너뛰고 로그에 기록)

> Opus, WMA 등 일부 포맷은 디코딩되지 않을 수 있습니다. 그런 파일이 많다면
> ffmpeg 기반 버전이 필요하니 알려주세요.

## 구조

- `src/main.rs` — eframe/egui GUI, 백그라운드 변환 스레드, 진행률 표시
- `src/convert.rs` — 디코딩(symphonia) → 리샘플링(rubato) → WAV 인코딩(hound)
